## 🌟 Overview

**ProPrint Studio Pro** is a high-precision, client-side web application designed for photographers, print labs, visa processing centers, and document service providers. It converts standard digital photographs into exact 300 DPI physical print sheets (A4, A3, Letter, Legal, 4×6 photo paper) with zero compression loss, accurate millimeter geometry, and press-ready cutting guides.

---

## ✨ Key Features

- **🎯 True 300 DPI Physical Scale**: Calibrated with exact physical millimeter geometry ($25.4\text{ mm} = 1\text{ inch} = 300\text{ px}$).
- **📋 Clipboard Intake (`Ctrl + V`)**: Copy any screenshot or image from your clipboard and paste directly into the studio.
- **🌍 International Visa & Passport Presets**:
  - 🇵🇰 Pakistan & UK Passport (`35 × 45 mm`)
  - 🇺🇸 US Visa / Passport (`2 × 2 in` / `50.8 × 50.8 mm`)
  - 🇪🇺 Schengen & Canada Visa (`35 × 45 mm`)
  - 🆔 NADRA Smart Card / CNIC (`30 × 40 mm`)
  - 📬 Stamp Size / Driving License (`25 × 25 mm`)
  - 🖼️ 4R Photo Paper Print (`4 × 6 in`)
- **🎛️ Studio Retouching Lab**:
  - Real-time Brightness, Contrast & Vividness controls
  - 1-Click **Auto Tone** Enhancement
  - Official **B&W / Grayscale** conversion
  - 90° Clockwise / Counter-Clockwise Rotation & Mirror Flip
- **📐 Flexible Placement Engine**:
  - **Auto Max**: Calculates maximum fit and neatly centers photos on sheet.
  - **Set Count**: Print exact requested copies (4, 8, 12, 16, or custom number).
  - **Single**: Center a single photo on sheet.
  - Configurable page margins (mm) and photo gaps (mm).
- **✂️ Professional Trimming Guides**:
  - Thin cutting boundary line (0.5 pt)
  - Press-standard Corner L-shaped Crop Marks
- **🖨️ Quadruple Export Hub**:
  1. **Direct Physical Print (`Ctrl + P`)**: Launches isolated zero-margin print dialog scaled to 100%.
  2. **300 DPI Vector PDF**: Built using `jsPDF` with physical millimeter dimensions.
  3. **300 DPI High-Res JPG**: Full-sheet master graphic.
  4. **Single Resized Photo**: For online visa / job application portal uploads.
